# Bookstore CLI Application

## Overview

The Book-Store-CLI Application is a command-line interface tool that allows users to manage a virtual bookstore. Users can perform various operations such as adding, reading,deleting and updating books.

## Installation 

### 1. Clone the repository
  To clone the project.

```bash 
git clone https://github.com/SanthoshKumar1903/Bookstore-cli.git
```
### 2. To run the project
 Make sure to add MONGODB_URI in your application.
 This application runs properly only when you connect to Database.

```bash
cd Bookstore-cli
npm install 
node main.js
```
